
# ClimaRuta ☀️

ClimaRuta es una aplicación web en desarrollo que busca facilitar la consulta del clima y la exploración de lugares, ayudando a los usuarios a conocer las condiciones meteorológicas de diferentes destinos.

## 🚀 Objetivo

Desarrollar una aplicación web que permita consultar información meteorológica y explorar destinos desde una interfaz sencilla, intuitiva y adaptable a diferentes dispositivos.

## 🛠️ Tecnologías utilizadas

- HTML5: estructura de la aplicación.
- CSS3: estilos, diseño y adaptación a dispositivos móviles.
- Google Fonts (Inter): tipografía de la interfaz.

## 📱 Diseño adaptable

La interfaz cuenta con un encabezado adaptable que muestra una navegación horizontal en computadores y un menú desplegable en dispositivos móviles.

## ⚙️ Cómo ejecutar el proyecto

1. Clona el repositorio o descarga sus archivos.
2. Abre la carpeta del proyecto.
3. Abre el archivo `index.html` en tu navegador.

También puedes utilizar la extensión Live Server de Visual Studio Code para visualizar los cambios durante el desarrollo.
